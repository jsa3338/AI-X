1. Oracle 설치 후 cmd 창을 띄움
2. system 계정 접속
	C:\~> sqlplus system/비번
	  * 비번을 모를경우 : sqlplus "/as sysdba
3. scott 이라는 유저ID를 생성. 비번은 tiger
	SQL> create user scott identified by tiger;   # 
4. 권한 부여 (최고권한인 dba)
	SQL> grant dba to scott;
5. 나가기
	SQL> exit;
6. scott 계정 접속 후 데이터 확인
	C:\~> splplus scott/tiger
