1절. SQLite 데이터 베이스 연동
- SQLite 데이터베이스는 별도의 DBMS 없이 SQL을 이용하여 DB엑세스 가능한 디스크 기반 DB
- 가볍게 프로토타입을 만드는 용도로 사용

<데이터베이스 연결>
1단계 : 연결 객체 만들기
	conn = sqlite3.connect(데이터베이스 경로)
2단계 : 커서객체 만들기
	cursor = conn.cursor()
3단계 : 커서객체로 sql 명령어 실행

  3.1 insert, update, delete 전송
	cursor.execute('''
	   # 입력 INSERT INTO MEMBER VALUES ("홍길동", 20, "hong@hong.com")
	   # 수정 UPDATE MEMEBER SET AGE=22 WHERE NAME = '홍길동'
	   # 삭제 DELELTE FROM MEMBER WHERE EMAIL IS NULL
	''')

  3.2 select 전송
	# SELECT문 실행결과를 받는 함수
	#     cursor.fetchone() : 결과를 한 행씩 받을 때 (튜플)
	#     cursor.fetchall() : 결과를 전체 받을 때 (튜플 list)
	#     cursor.fetchmany(n) : 결과를 n행 받을 때 (튜플 list)
	#     cursor.descrption() : header 내용을 포함한 내용들 (list)
	cursor.execute('''
		SELECT NAME, AGE+1 NEXTAGE, EMAIL 
	        		FROM MEMBER
			ORDER BY AGE   
	''')
	members = cursor.fetchall()
	df = pd.DataFrame(members, 
                  columns=[header[0] for header in cursor.description])
	df
