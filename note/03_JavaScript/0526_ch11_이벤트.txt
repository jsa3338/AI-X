ch11. 이벤트

1. 인라인 이벤트 모델
	html 태그 안에 이벤트 속성과 함수를 넣고, script 섹션에서 해당 함수를 정의해주는 방식

2. 기본 이벤트 모델
	script 섹션에서 이벤트 속성(on으로 시작하는 속성)에 function을 할당.

3. 표준 이벤트 모델
	이벤트 리스너를 추가
	객체.addEventListener('이벤트이름', '리스너함수')

4. 이벤트 강제 발생
	이벤트 함수 안에 다른 이벤트 함수 등을 넣어 강제 실행 가능
	표준모델의 경우    객체.이벤트이름()  로 함수를 지정가능하다
	 (ex)  기본 : btnB.onclick();  -> 표준 : btnB.click(); 

5. 이벤트 제거
	특정조건을 만족할 경우 해당 이벤트를 제거하는 방법
	- 기본 : 객체.이벤트속성 = null; 선언
	- 표준 : 객체.removeEventListener('이벤트이름', '이벤트함수')
	** 단, 표준 방식의 경우 앞서 함수를 선언하는 것이 간편하다

6. 이벤트 제한
	유효성 체크 등을 통해 해당 이벤트를 무효화 시키는 방식
	- 기본 : return false;
	- 표준 : 이벤트객체.preventDefault();
